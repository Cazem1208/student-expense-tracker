# Student Expense Tracker

A simple student expense tracker built as a beginner web development project.

## Features

- Add expenses
- Record expense name, amount, category and date
- View all expenses
- Delete expenses
- Calculate total spending
- Filter expenses by category
- Save data using localStorage
- Responsive design

## Technologies

- HTML
- CSS
- Vanilla JavaScript
- localStorage
- Git
- GitHub

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start adding expenses.

No backend or additional installation is required.

## Purpose

This project was created as a beginner web development project to practice HTML, CSS, JavaScript, DOM manipulation, localStorage, Git and GitHub.
